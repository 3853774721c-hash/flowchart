# flowchart
Convert C language into a flowchart
FlowC is a web-based flowchart generator that turns C and C++ code into visual diagrams. Users can paste code or upload a source file, select a function, and generate a flowchart showing its main control structures.

The tool supports common structures such as conditional statements, loops, and switch statements. It also allows users to export a flowchart as a single-page PDF through the browser’s print dialog. Files are processed locally in the browser and are not uploaded to a server.

FlowC is designed for learning, teaching, and understanding program logic. It uses a lightweight parser rather than a full compiler, so complex syntax and generated diagrams should be reviewed against the original code.
